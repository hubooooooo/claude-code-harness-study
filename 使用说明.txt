   learn-claude-code 使用说明（学生版 · Mac）
   先看这一页，照着做就行（准备约 5 分钟）
════════════════════════════════════════════════════

只需要准备两样东西：
   ① 能上网（装依赖 + 调用 AI 需要联网）
   ② 一个 DeepSeek 的 API Key（第一次运行会提示你粘贴）

Python 不用自己装：直接双击「启动.command」，脚本会自动检测；如果电脑上没有
合适版本的 Python，会先尝试安装 Apple 命令行工具，仍不行会自动下载并安装
官方 Python。安装时如果弹出管理员密码框，输入你的 Mac 开机密码即可。

下面按顺序做。

──────────────────────────────────────────
第 0 步：双击启动（推荐）
──────────────────────────────────────────

   1. 找到本文件夹里的「启动.command」
   2. 双击它
   3. 第一次运行时，脚本会自动检查并处理 Python、自动安装依赖
   4. 看到 DeepSeek Key 输入提示时，粘贴 key 并回车

   ⚠️ 如果双击后提示“无法打开/来自身份不明的开发者”：
     按住 Control 点按「启动.command」→ 选“打开” → 再点“打开”。
   ⚠️ 如果弹窗询问是否安装开发工具：点“安装”，完成后脚本会自动继续。
   ⚠️ 如果弹出管理员密码框：输入 Mac 开机密码（输入时屏幕可能不显示，正常）。

──────────────────────────────────────────
开始上课（每次）
──────────────────────────────────────────

如果不想用「启动.command」，也可以用系统终端：
   1. 打开「终端」
   2. 输入 python3 和一个空格
   3. 把本文件夹里的 run.py 直接拖进终端窗口
   4. 回车

（VS Code 里也可以新建终端后运行：python3 run.py）

第一次运行会自动做两件事（需联网，约 1 分钟）：
   ① 自动创建环境并安装依赖（不用你管，等它跑完即可）
   ② 提示你粘贴 DeepSeek API Key
      → 去 https://platform.deepseek.com/ 注册并领取 key
      → 粘贴到终端里，回车（以后就不用再输了）

──────────────────────────────────────────
上课时怎么操作
──────────────────────────────────────────
   启动后会出现菜单，输入 s01 ~ s17 中任意一个回车，开始上课。
   在课程里输入 q：退出本节课，回到菜单。
   在菜单里输入 s02 等编号：切换下一课。
   在菜单里输入 q：退出整个程序。

──────────────────────────────────────────
常见问题
──────────────────────────────────────────
Q: API Key 填错了怎么办？
A: 运行课程时看到 401 / authentication 报错，就是 key 错了。
   在菜单里输入 key 回车，重新粘贴；或终端运行：python3 run.py setkey

Q: 提示依赖安装失败？
A: 多半是网络问题，重试一次；还不行就换个网络（比如手机热点）再试。
   手动安装（在终端里 cd 到本文件夹后执行）：
       python3 -m venv .venv
       .venv/bin/python -m pip install -r requirements.txt

Q: 装依赖时卡住 / 下载很慢？
A: 程序默认使用国内清华镜像，一般很快；若卡住，换个网络重试。

   learn-claude-code 使用说明（学生版 · Mac）
   先看这一页，照着做就行（准备约 5 分钟）
════════════════════════════════════════════════════

只需要准备三样东西：
   ① 电脑上装好 Python（3.9 以上）
   ② 能上网（装依赖 + 调用 AI 需要联网）
   ③ 一个 DeepSeek 的 API Key（第一次运行会提示你粘贴）

下面按顺序做。

──────────────────────────────────────────
第 0 步：装 Python（只做一次）
──────────────────────────────────────────

【先检查】
   打开「终端」，输入：  python3 --version
   看到 3.9 / 3.10 / 3.11 / 3.12… 就说明装好了，直接跳到「开始上课」。
   什么都没显示，或提示找不到命令，就按下面装：

【怎么装】
   方法一（最简单）：在「终端」里输入 python3 回车，系统会弹窗提示
   安装命令行工具，点「安装」，装完再检查一次。
   方法二：打开 https://www.python.org/downloads/ 下载安装包，一路下一步。

──────────────────────────────────────────
开始上课（每次）
──────────────────────────────────────────

推荐用 VS Code：
   1. 打开 VS Code → 菜单「文件」→「打开文件夹」→ 选本文件夹
   2. 打开内置终端：菜单「终端」→「新建终端」（快捷键 Ctrl+`）
   3. 在终端里输入：  python3 run.py   然后回车

   ⚠️ 不要点右上角的「▶ 运行」按钮，一定要在终端里输入上面的命令。

或者用系统终端（最简单，最推荐）：
   1. 打开「终端」
   2. 输入 python3 和一个空格
   3. 把本文件夹里的 run.py 直接拖进终端窗口
   4. 回车

（也可以直接双击「启动.command」；如果双击没反应，就用上面两种方式之一。）

第一次运行会自动做两件事（需联网，约 1 分钟）：
   ① 自动创建环境并安装依赖（不用你管，等它跑完即可）
   ② 提示你粘贴 DeepSeek API Key
      → 去 https://platform.deepseek.com/ 注册并领取 key
      → 粘贴到终端里，回车（以后就不用再输了）

──────────────────────────────────────────
上课时怎么操作
──────────────────────────────────────────
   启动后会出现菜单，输入 s01 ~ s17 中任意一个回车，开始上课。
   在课程里输入 q：退出本节课，回到菜单。
   在菜单里输入 s02 等编号：切换下一课。
   在菜单里输入 q：退出整个程序。

──────────────────────────────────────────
常见问题
──────────────────────────────────────────
Q: API Key 填错了怎么办？
A: 运行课程时看到 401 / authentication 报错，就是 key 错了。
   在菜单里输入 key 回车，重新粘贴；或终端运行：python3 run.py setkey

Q: 提示依赖安装失败？
A: 多半是网络问题，重试一次；还不行就换个网络（比如手机热点）再试。
   手动安装（在终端里 cd 到本文件夹后执行）：
       python3 -m venv .venv
       .venv/bin/python -m pip install -r requirements.txt

Q: 装依赖时卡住 / 下载很慢？
A: 程序默认使用国内清华镜像，一般很快；若卡住，换个网络重试。

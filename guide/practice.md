# 练习：拿到需求，做出判断

这一篇检验你有没有学会这门课最核心的能力：**给你一个产品需求，你能判断要不要用 Agent、走哪条路、用哪些部件。**

一共 7 道题。前 6 道题的答案各不相同，五条路线和「不用 Agent」各占一道，但题目顺序是打乱的。第 7 道是综合验收题，用于结课考核。

---

## 怎么做

1. 先读背景和已知条件，**不要先看「思考提示」**。
2. 按 [选型篇](README.md) 开头的五步判断流程推导。
3. 把结论填进 **判断结论卡**（格式见选型篇的「判断结论卡」一节，也可以直接抄下面这份）。
4. 写完再看「思考提示」，查漏补缺。
5. 最后对照 [参考答案与评分要点](practice-answers.md)，用文末的自查清单打分。

> **老师上课时**：可以每次课后布置一两道，下一节课开头请两三位同学讲自己的结论卡，再对照参考答案点评。重点听学生的推导过程，路线选得不一样但理由站得住，也可以给分。

```text
判断结论卡：<需求名称>

1. 要不要 Agent：要 / 不要 / 部分环节要
   - 需要 Agent 的环节：
   - 不需要的环节，用什么代替：

2. 路线：① 直接用成品  ② 用厂商开发包  ③ 用通用框架  ④ 用低代码平台  ⑤ 完全自研
   - 选：
   - 理由（对应五个问题里的哪几条）：
   - 为什么不选其他几条（至少排除两条）：

3. 部件
   - 如果自研：启用的部件和对应症状；暂不启用的部件和「出现什么症状再加」
   - 如果不自研：这条路自带哪些部件；缺哪些；缺的致不致命，怎么补

4. 关键规则（至少三条）：
5. 指标与目标值：
6. 什么条件下换路线：
```

## 第 1 题：销售团队的查询助手（难度 ★★）

### 背景

一家做工业零部件的公司，销售团队 50 人。销售每天要反复问同样的问题：「这个型号的参数是多少？」「某客户最近下过什么订单、上次是谁跟进的？」「这个量级的报价规则是什么？」答案分散在产品文档和 CRM 系统里，销售只能去问内勤，内勤每天被问得团团转。

| 条件 | 情况 |
|---|---|
| 团队 | 没有工程师。有一位运营同学自学过 Dify，搭过简单的问答机器人 |
| 操作 | 只查询，不修改任何数据 |
| 数据 | 公司允许使用国内的大模型服务，也允许在内网自己部署开源软件 |
| 入口 | 销售都在飞书里办公 |
| 时间 | 老板要求两周内先上线试用 |

### 思考提示（先自己做完再看）

- 只查询不修改，权限这件事就不重要了吗？想一想：销售 A 能不能查到销售 B 的客户？
- 「两周上线」和「没有工程师」分别指向哪条路？
- 什么情况出现时，需要换路线？

## 第 2 题：SaaS 产品里的数据报表助手（难度 ★★）

### 背景

一家做跨境电商数据分析的 SaaS 公司，客户是海外的中小卖家。公司想在产品里加一个 AI 助手：客户用一句话提问，比如「上个月哪些商品退货率最高，做成图表发我邮箱」，AI 自己去查数据、画图、生成报告。

| 条件 | 情况 |
|---|---|
| 团队 | 8 名工程师，没有做过 Agent |
| 模型 | 公司已经和一家海外模型厂商签了企业协议，客户和数据都在海外，没有换模型的计划 |
| 数据 | 每个客户只能看到自己店铺的数据 |
| 时间 | 两个月内上线 |

### 思考提示（先自己做完再看）

- 这是做进产品卖给客户，还是给自己团队用？这一点排除了哪条路？
- 「认定一家模型」意味着什么？选这条路前，还要查清楚哪些条款？
- 有的查询要跑好几分钟，客户要一直等吗？
- 「发我邮箱」是对外操作，权限放在哪一档？

## 第 3 题：商品详情页文案批量生成（难度 ★）

### 背景

一家卖家居用品的电商公司，每个月上新约 2000 个商品。运营要根据商品参数表（材质、尺寸、颜色、卖点）给每个商品写一段详情页文案，再上传到店铺后台。老板说：「做个 Agent 来写文案吧。」

| 条件 | 情况 |
|---|---|
| 团队 | 运营 3 人，没有工程师 |
| 数据 | 商品参数表是 Excel |
| 要求 | 文案风格统一，不能出现「最好」「第一」这类违反广告法的词 |

### 思考提示（先自己做完再看）

- 每个商品的处理步骤是不是完全一样？下一步做什么，需要看上一步的结果吗？
- 回顾选型篇的「什么时候不该用 Agent」，这题落在哪几条？
- 违禁词检查，交给模型做可靠，还是用普通程序做可靠？
- 怎么向老板解释「不用 Agent」，又不显得是在推脱？

## 第 4 题：律所的合同审查系统（难度 ★★★）

### 背景

一家 200 人的律所，律师每天要审大量商务合同，检查付款条款、违约责任、保密条款、管辖法院等有没有风险。采购、租赁、劳动、投资四类合同，审查口径各不一样。律所希望 AI 先过一遍、标出风险点，律师再复核。做成以后，律所还打算把这套系统**卖给其他中小律所使用**。

| 条件 | 情况 |
|---|---|
| 团队 | 律所自己没有工程师，长期合作一支 4 人的外包开发团队，做过几个大模型项目 |
| 数据 | 合同是客户的保密资料，客户合同里经常约定数据不能出境 |
| 模型 | 想同时试几家国内模型，挑效果最好的，以后也可能换 |
| 文档 | 单份合同常有几十页，附件更多 |
| 要求 | 审查结果最终由律师签字负责 |

### 思考提示（先自己做完再看）

- 「数据不能出境」和「可能换模型」排除了哪几条路？
- 「卖给其他律所」这一条，会让哪个方案在许可证上出问题？
- 四类合同的审查口径，最适合用哪个部件来管？
- 几十页的合同，会遇到哪个部件要解决的问题？有几种办法？
- 「必查条款都查过了」能不能变成一份可以客观核对的清单？对应哪个部件？

## 第 5 题：行政财务团队的日常提效（难度 ★）

### 背景

一家 300 人的公司，行政和财务一共 12 人。日常工作有：整理报销单据、Excel 对账、从一堆邮件里汇总信息、写通知和会议纪要。大家听说 AI 能帮忙干这些活，希望尽快用上。

| 条件 | 情况 |
|---|---|
| 团队 | 没有工程师，也不打算招 |
| 数据 | 公司允许使用海外 AI 服务，但要求签企业协议、数据不能被拿去训练模型 |
| 时间 | 希望下周就能用 |
| 用途 | 只给内部员工自己用，不对外 |

### 思考提示（先自己做完再看）

- 这是给自己团队提效，还是做进产品给客户？这些活是不是现成工具本来就擅长的？
- 如果是买现成的，产品经理还要做什么判断？哪些部件变成了「配置项」？
- 财务数据很敏感，哪些操作要先问人，哪些文件夹不能让 AI 碰？

## 第 6 题：AI 编程工具创业公司（难度 ★★★）

### 背景

一家创业公司，产品本身就是一个给程序员用的编程 Agent，要和市面上已有的编程 Agent 产品正面竞争。他们计划靠下面几点拉开差距：

- 超大的代码库，Agent 也不会忘掉前面看过的内容；
- 多个 Agent 可以同时改同一个项目的代码，互不冲突；
- 企业客户可以任选模型，包括部署在客户自己机房里的模型；
- 企业管理员可以非常细地配置权限，比如「这个部门的 Agent 只能改前端目录，不能执行数据库命令」。

| 条件 | 情况 |
|---|---|
| 团队 | 30 名资深工程师，其中多人做过开发工具 |
| 融资 | 刚完成一轮融资，可以投入一年做第一版 |
| 客户 | 主要卖给大企业，客户对安全审计要求很高 |

### 思考提示（先自己做完再看）

- 五个问题里的最后一个：Harness 本身是不是这家公司的核心竞争力？
- 「任选模型、包括私有部署」排除了哪条路？
- 对照「各条路线自带哪些部件」：他们最看重的几项能力，现成方案提供得怎么样？
- 自研不等于 16 个部件全上。哪些可以第一版先不做？

## 第 7 题（综合验收）：夜间运维值班助手（难度 ★★★）

> 这道题用于结课验收。请完整填写判断结论卡的全部六项。

### 背景

一家做在线教育的公司，服务器夜里偶尔出故障，告警会打到值班工程师手机上。工程师常常半夜被叫起来，结果发现只是重启一下服务就好。公司希望 AI 在夜里先处理一轮，处理不了再叫人。

| 条件 | 情况 |
|---|---|
| 团队 | 运维组 5 名工程师，都会写代码 |
| 操作 | 常见处理动作：查日志、查监控、重启服务、扩容、回滚版本 |
| 风险 | 回滚和扩容如果做错，可能影响几十万在线学生 |
| 数据 | 公司已经在内网部署了一套国产大模型，日志不允许发到公司外面 |
| 时间 | 告警多发生在凌晨，没有人盯着 |

### 思考提示（先自己做完再看）

- 「查日志、判断原因、决定怎么处理」这件事需要 Agent 吗？为什么？
- 「日志不能发到公司外面」排除了哪几条路？
- 五个处理动作，分别放在权限的哪一档？「先问人」在凌晨意味着什么？
- 「重启以后服务恢复了没有」能不能客观验证？对应哪个部件？
- 没人盯着时出了错，靠什么兜底？第二天谁来复盘、看什么记录？

## 自查清单

每道题写完，逐条检查。每条做到算 1 分，满分 10 分。7 分以上算合格。

| # | 检查项 |
|---|---|
| 1 | 先回答了「要不要 Agent」，并且把不需要 Agent 的环节拆了出来 |
| 2 | 路线选择对应到了具体条件：内部还是对外、有没有工程师、模型和数据限制、Harness 是不是核心竞争力 |
| 3 | 至少排除了两条路线，并说清了理由 |
| 4 | 自研时，每个启用的部件都对应一个具体症状；不自研时，对照了这条路缺哪些部件、致不致命 |
| 5 | 每个暂不启用的部件，都写了「出现什么症状再加」 |
| 6 | 所有「写」操作（改数据、发消息、花钱）都放进了权限三档，并且有「绝对禁止」项 |
| 7 | 写了步数、费用或时间上限 |
| 8 | 说清楚了敏感数据怎么处理：记不记、存多久、谁能看 |
| 9 | 指标有具体的目标值，越权、误操作类指标的目标是 0 |
| 10 | 写了什么条件下换路线 |
